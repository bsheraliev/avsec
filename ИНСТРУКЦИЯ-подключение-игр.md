# AvSec — режим «витрина»: как подключать игры и вопросы

Сейчас **активны первые 5 плиток**, остальные помечены бейджем **🔧 в разработке**:
по нажатию игра не запускается, показывается тост *«Раздел на стадии разработки —
скоро будет доступен»* (рус/тадж/англ).

Активны по умолчанию (первые 5):
Видеоуроки · Основы АБ и угрозы · Пропуска и доступ · Зоны ограниченного доступа · Досмотр

Дополнительно: в активных тестах показывается **только 40% вопросов** категории
(остальные 60% «придержаны» до подключения):
- Основы АБ: 8 → 4 · Пропуска и доступ: 16 → 7 · Зоны ограниченного доступа: 12 → 5 · Досмотр: 12 → 5

---

## Где ручки

Файл **`app.js`**, вверху, сразу под списком `MENU`:

```js
const WIP_AFTER = 5;     // сколько плиток активно в начале меню
const LIVE_EXTRA = [];   // id игр (go), всегда активных независимо от позиции
const QUIZ_KEEP = 0.4;   // доля вопросов категории сейчас (0.4 = −60%)
```

## Как подключить позже

**1. Открыть конкретный тест полностью (точечно).**
Добавь его id (`go`) в `LIVE_EXTRA`. Пример — открыть «Запрещённые предметы» и «Действия при угрозе»:
```js
const LIVE_EXTRA = ["quiz-prohibited", "quiz-response"];
```

**2. Открыть больше плиток сразу.**
Подними число: `const WIP_AFTER = 7;`

**3. Открыть всё меню целиком.**
```js
const WIP_AFTER = 99;
```

**4. Вернуть вопросы в тестах.**
- все вопросы → `const QUIZ_KEEP = 1;`
- частично → например `0.7` (останется 70%).

> `QUIZ_KEEP` режет только тематические тесты (`quiz-*`). «Экзамен»/«Блиц» берут
> случайные 15 вопросов из всей базы — на них доля не влияет.

## После любой правки

1. В **`sw.js`** подними версию кэша: `const CACHE = "avsec-v7";` → `"avsec-v8";`
   (чтобы установленные PWA подхватили обновление).
2. Опубликуй (тот же процесс деплоя, что и для остального AvSec).
   Сайт: https://bsheraliev.github.io/avsec/
3. На устройстве закрой и заново открой приложение (иногда дважды) — service
   worker отдаст новую версию.

# Папка снимков TIP (Threat Image Projection)

Сюда кладутся **реальные рентгеновские снимки** для модуля «Распознавание на рентгене».
Приложение подхватывает их автоматически из файла `scenes.json` (см. ниже) и показывает
вперемешку со встроенными векторными сценами.

---

## ⚠️ Главное правило: реальные снимки НЕ коммитятся в публичный репозиторий

Репозиторий `bsheraliev/avsec` **публичный**, и сайт раздаётся через GitHub Pages.
Любой файл в нём скачивается кем угодно по прямой ссылке — проверка лицензии
(`license.js`) защищает только интерфейс, но **не файлы**.

Реальные TIP-снимки нельзя публиковать, потому что:

1. **Служебная информация ограниченного доступа.** TIP-библиотеки применяются для
   проверки бдительности операторов досмотра. Публикация даёт возможность изучить,
   как выглядят угрозы на снимке, и подготовиться к обходу контроля.
2. **Права третьих лиц.** Библиотеки производителей досмотровой техники (Smiths
   Detection, Rapiscan, Nuctech и др.) лицензируются аэропорту/эксплуатанту и не
   подлежат передаче и публикации.
3. **Открытые датасеты не подходят.** SIXray, OPIXray, GDXray разрешены только для
   научных целей и несовместимы с коммерческим продуктом.

Поэтому в `.gitignore` прописано игнорирование всех изображений в этой папке.
**Не снимайте это правило.**

## Как использовать снимки легально

| Сценарий | Что делать |
|---|---|
| Обучение внутри организации | Снимки хранятся локально; приложение разворачивается во внутренней сети или раздаётся как офлайн-PWA/APK, не через публичный сайт |
| Демонстрация заказчику | Использовать встроенные векторные сцены — они собственные и публикуются свободно |
| Публичная версия | Только векторные сцены. Реальные снимки — никогда |

Источник снимков должен быть законным: собственные материалы аэропорта, полученные
с разрешения службы авиационной безопасности, либо переданные вам правообладателем
с правом использования в подготовке персонала.

## Формат

Положите изображения в эту папку и создайте рядом `scenes.json`:

```json
{
  "scenes": [
    {
      "id": "tip-001",
      "title": "Ручная кладь · рейс TJ-101",
      "task": "Найдите запрещённый предмет",
      "img": "./xray/tip-001.jpg",
      "vw": 400,
      "vh": 260,
      "targets": [
        {
          "x": 150, "y": 90, "w": 70, "h": 45,
          "name": "Нож",
          "why": "Колюще-режущие предметы запрещены в ручной клади."
        }
      ],
      "hint": "Обратите внимание на металлический силуэт в центре."
    }
  ]
}
```

**Поля:**

- `img` — путь к файлу относительно корня приложения;
- `vw` / `vh` — система координат снимка (по умолчанию 400 × 260). Проще всего
  указать реальные пиксельные размеры изображения и задавать координаты в пикселях;
- `targets[]` — зоны правильного ответа: `x`, `y` — левый верхний угол, `w`, `h` —
  размеры в той же системе координат. Для «чистого» снимка оставьте `targets: []`
  и добавьте `"clean": true` и `"cleanWhy": "…"`;
- `why` — разбор, показывается после ответа. Пишите по существу: почему предмет
  запрещён и по какому признаку опознаётся на снимке.

Файл `scenes.example.json` в этой папке — готовый образец для копирования.

## Как определить координаты зон

1. Откройте снимок в любом редакторе, показывающем координаты курсора (Paint, GIMP,
   Photoshop, IrfanView).
2. Наведите на левый верхний угол предмета — это `x`, `y`.
3. Наведите на правый нижний — вычтите: `w = x2 − x1`, `h = y2 − y1`.
4. Зону лучше делать чуть больше предмета: попадание засчитывается по прямоугольнику.

## Проверка

После добавления `scenes.json` откройте модуль «Распознавание на рентгене» —
снимки появятся в общей ротации. Если их нет, проверьте в консоли браузера, что
`./xray/scenes.json` отдаётся без ошибки и является корректным JSON.
